# Nebula Forge Games — Simple Static Website

## Codveda Technologies Web Development Internship

**Level:** Level 1  
**Task:** Task 1 — Simple Static Website  
**Project Type:** Multi-page Static Website

---

## Project Overview

Nebula Forge Games is a fictional indie game studio website created as part of the Codveda Technologies Web Development Internship.

The website presents the studio, its games, team, and contact information through a modern, dark-themed interface. The project was designed to demonstrate fundamental web development skills using HTML and CSS.

The website focuses on providing a simple and responsive experience across different screen sizes.

---

## Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- CSS Media Queries
- Google Fonts

---

## Website Pages

The website contains four main pages:

### Home

Introduces Nebula Forge Games and features some of the studio's games.

### About

Provides information about the fictional studio, including:

- Introduction
- History
- Mission
- Values
- Team members

### Games

Displays the studio's games:

- **Echoes of Ember** — Fantasy RPG
- **Neon Drift** — Racing
- **Little Astronaut** — Space Adventure

### Contact

Provides a contact form and links to the studio's social platforms.

---

## Responsive Design

The website uses CSS media queries to adapt the layout to smaller screens.

The layouts were tested at different viewport widths, including:

- Desktop
- Tablet
- Mobile
- Small mobile screens

Flexbox and CSS Grid are used to organize and adapt different sections of the website.
