## Project Overview

This project is a personal portfolio webpage created as part of the Codveda Technologies Web Development Internship.

The website introduces me as a Computer Science student, presents some of my projects and skills, and provides ways for visitors to get in touch with me.

The design was adapted from a tutorial project, with modifications made to the content, design, and implementation. Additional CSS and web development techniques were explored as part of the learning process.

## Responsive Design

The website uses CSS media queries to adapt the layout for smaller screens.

On mobile devices, the navigation links are replaced by a hamburger menu. The About section also changes from a two-column layout to a single-column layout.
